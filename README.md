# PointRead English

一个纯静态英文点读阅读 App 原型。

## 功能

- 类手机 App 的封面输入页和沉浸阅读页
- 点击单词高亮、朗读、显示中文释义气泡
- 点击“译文”查看全文中文翻译，译文会缓存，也可以手动修正保存
- 内置常用英文阅读词库；未收录词会在线查询并缓存
- 划选短语后朗读和收藏
- 收藏生词本，本地保存
- 字号、行距、深浅色、读过变淡

## 说明

界面使用护眼色背景，不包含截图来源里的平台水印、社交栏或图书背景元素。

## 使用

直接打开 `index.html`，或在本目录启动任意静态服务器。

## GitHub Pages 部署

这个项目是纯静态 App，不需要打包构建。把整个 `english-reader-app` 目录推到 GitHub 仓库后，在仓库 Settings -> Pages 里选择对应分支和根目录即可。

已适配：

- 所有资源使用相对路径，支持部署在 `https://用户名.github.io/仓库名/`
- `.nojekyll` 避免 GitHub Pages 处理静态文件
- `manifest.webmanifest` 和 `sw.js` 支持安装到手机桌面与基础离线缓存
- 查词和全文翻译接口使用 HTTPS；查到的词和译文会缓存到当前浏览器
